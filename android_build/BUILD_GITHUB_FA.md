# ساخت APK با گوشی و GitHub Actions

این پروژه برای ساخت APK با GitHub Actions آماده شده است.

## امکانات نسخه فعلی
- ابتدا آخرین آدرس ذخیره‌شده سرور را باز می‌کند.
- اگر سرور در دسترس نباشد، فرم ورود آدرس و پورت نمایش داده می‌شود.
- آدرس جدید ذخیره می‌شود و دفعه بعد ابتدا همان آدرس امتحان می‌شود.
- نمونه آدرس: `192.168.1.9` و پورت `8080`.

## ساخت
در GitHub مخزن را بسازید، محتویات ZIP را در آن قرار دهید و به شاخه `main` یا `master` push کنید. همچنین از بخش Actions می‌توانید workflow را دستی اجرا کنید. پس از پایان Build، فایل `LAN-Messenger-debug` را از بخش Artifacts دانلود کنید.
